# ФСП Вектор: заключительный функциональный аудит

Дата: 7 октября 2026, МСК. Проверяется локальный конкурсный прототип. Дизайн, CSS, визуальная структура и анимации этой итерацией не изменены. Презентация по указанию команды отложена. Исходники остаются в локальном Git без remotes; публикация и загрузка на конкурсную платформу не выполнялись.

## Результат и изменения

Полный путь обратного найма работает с сохранёнными серверными данными: регистрация, подтверждение почты, опрос, формальный экзамен, категория, публикация, потребность работодателя, подбор, персональное предложение, принятие и отдельное разрешение компании на контакты. Самостоятельный отклик на вакансию также сохраняется. Контакты исчезают из дальнейших ответов после отзыва; повтор принятия старого приглашения не восстанавливает разрешение.

Закрыты обнаруженные при аудите пробелы:

- Версионируемая история опроса; просмотр приглашения как отдельная дата; серверная доступность следующей формальной попытки.
- Практика по потребности приглашения/вакансии с явной картой измерения, отдельным scope и доказательствами только для соответствующей компании. Результат не изменяет глобальную категорию.
- Сохранённый контекст уточнения подборки; обязательные навыки подтверждаются формальным экзаменом. Хорошие дополнительные навыки не маскируют слабую обязательную компетенцию.
- Недельная объективная практика с устойчивой ротацией, серверными попытками, сроком повторения и отдельным согласием на напоминания. После изменения специализации или действующего грейда выдаётся соответствующая текущему маршруту задача; прежние задания и результаты сохраняются, повторные запросы не создают дубли и лишние уведомления.
- Завершение SSE после утраты сессии/согласия; минимальные исторические проекции после отзыва обработки; терминальный статус неудачной доставки писем.
- Банк расширен до 186 семейств. Middle/Senior требуют сложных предметных действий; пропуск критической темы блокирует PASS. Старая попытка сохраняет собственную рубрику.
- Исправлен разбор канонических навыков, списков с «будут плюсом» и неоднозначности между специализацией Security и навыком Web security. Неизвестные поля не придумываются; результат требует подтверждения.
- Фильтр ФСП принимает фактический sync_ok и сохраняет демо-происхождение. Единый вход со страницы работодателя передаёт роль employer.
- Неизвестные зарплатные ожидания обозначены текстом; закрытые контакты имеют явное сообщение даже в принятом приглашении.
- Права для списка профилей читаются пакетно в пределах одного запроса/транзакции. Кеш не разделяется между работодателями и инвалидируется при изменении разрешений.
- OpenAPI содержит 73 маршрута и 58 схем: основные DTO, роли, cookie/CSRF, ограничения запросов, ошибки, PDF, SSE и redirect. Расширяемые ответы честно объявлены GenericObject.
- Закрыты известные advisory в Python lockfile; усилены production/OIDC TLS guards; добавлена проверяемая согласованная резервная копия и восстановление в отдельную БД.

## Производительность и ресурсы

[HTTP benchmark](http-benchmark.json): 120 реальных авторизованных запросов, concurrency8, прогретый API/PostgreSQL, 45 опубликованных синтетических профилей, 0 ошибок. p95: банк **235,21 мс**, фильтр **230,77 мс**, категории **240,36 мс**, dashboard **495,92 мс**; 34,03 запроса/с. Заключительный замер выполнен после перезапуска исправленного API. Это чтения, не измерение экзамена, записи ranking и промышленной ёмкости.

[Ресурсы](resources.json): Windows, i5-11300H, 8 логических CPU, 15,7GB RAM. Сумма working sets процессов стенда **1099,28MB**, включая PostgreSQL/identity/mail; общие страницы могут учитываться несколько раз. Двухсекундная выборка CPU в покое не является нагрузочным тестом. До readiness при уже установленных runtimes — **8,653 с**; скачивание, первый setup и web build в это время не входят.

## Происхождение и сдаваемые материалы

Открытые репозитории конкурентов анализировались только чтением по зафиксированным коммитам. Их код не копировался, не импортировался и не запускался. Внутренние исследовательские снимки и сравнительные заметки исключены из сдаваемого исходного архива. Реализация, данные и контрольные задачи авторские; зависимости и шрифты имеют собственные лицензии: [THIRD_PARTY_NOTICES](../../THIRD_PARTY_NOTICES.md), [LICENSE](../../LICENSE).

Комплект включает читаемые исходники, технический PDF, видео, инструкции и manifest с SHA256. Он не содержит .local, .runtime, .venv, БД, почтовый inbox, резервные копии, node_modules и .next. Предварительный исходный архив устанавливается заново; упаковщик затем проверяет точное равенство всех runtime/source/data/lock файлов проверенному архиву. Добавленные после проверки документы и отчёты не меняют проверенный код.

## Существенные границы

**DEMO_ONLY:** сведения ФСП и люди/компании синтетические, реальный API Федерации не предоставлен. **NOT_MEASURED:** человеческая калибровка грейдов, человеческая независимая разметка, профессиональная валидность, реальные наймы, промышленная нагрузка. **CONFIGURED_NOT_RUN:** Docker Compose и отдельный Linux/gVisor judge; на Windows произвольный код кандидата не исполняется. Публичное production развёртывание не выполнялось.

Видеопрохождение использует reference solver только по публичным условиям выданных заданий. Оценку проводит обычный API; категория не менялась скрытыми записями в БД. Видео является монтажом реальных ключевых экранов с паузами для чтения, а не непрерывной записью мыши. Презентация, включая обязательные слайды7–11, остаётся отдельным материалом команды.
