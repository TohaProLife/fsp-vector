# Аудит локальной сборки ФСП Вектор

Дата: 7 октября 2026. Среда: Windows, Node 24.16.0, Python 3.14.6,
PostgreSQL 18.6, Keycloak 26.8.0, Mailpit 1.31.4. Режим `local_demo`.

Это оригинальная работа данного workspace. Git локальный, remote отсутствует;
исходники не опубликованы. Презентация не создавалась и не изменялась.

Единственное предупреждение pytest: Starlette использует deprecated alias
`anyio.abc.BlockingPortal`; проверки завершились успешно.

Smoke использовал только вымышленные `@vector.local` личности и локальные
сервисы. Письмо действительно доставлено через SMTP в Mailpit, одноразовый
token подтверждения повторно отвергнут. Подбор реально выполнен по PostgreSQL.
Контакты появились после принятия приглашения только у одной компании,
у второй остались закрыты. Отзыв разрешения сразу закрыл доступ; повторное
принятие старого приглашения не восстановило разрешение. ATS получил настоящий
HTTP запрос с проверенной HMAC подписью и идентификатором идемпотентности.
Персональные контакты не передавались в webhook payload. Unicode PDF
экспортирован и импортирован через ограниченный дочерний процесс; импорт
возвратил несохранённый `SELF_DECLARED` черновик и точные цитаты без изменения
грейда и evidence.

## Исправления по результатам аудитов

- Убраны расхождения форм и API, ложные подтверждения языков по общим вопросам,
  автоматическая сила evidence и утечки контактов через сохранённые подборки.
- Сохранение ответов завершает запись до отправки формы; изменение ответа
  во время запроса повторно сохраняется, ошибки не запускают бесконечный retry.
- Холодная отдельная страница экзамена восстанавливает CSRF через `/auth/me`
  перед первой записью; конкурентные записи используют один запрос сессии.
  Неудачное восстановление сессии прекращает запись. Фактические autosave,
  reload и отправка результата проверены в браузере на вымышленном аккаунте.
  Разбор результата показывает задания, человеческие сообщения и баллы.
- `REST API` валидируется как контекст `API` с сохранением исходного ввода.
  Рекомендованные контексты поступают из каталога; смена специализации не
  смешивает маршруты языков. Неизвестная технология явно отклоняется.
- Формат работы и занятость «любой» симметричны для обеих сторон; конкретные
  несовместимые требования по-прежнему исключают кандидата.
- Одновременные start/submit/accept и гонки отзыва согласия проверены на
  PostgreSQL. Два worker не забирают один outbox event одновременно.
- PDF не распаковывается в процессе API: 6 секунд, 512 MiB, 15 страниц,
  40 000 символов, 3 слота. На Windows JobObject охватывает только созданный
  дочерний процесс, ограничивает число процессов до 1 и убивает его при
  закрытии. Ошибка назначения JobObject прекращает импорт до передачи PDF.
- Закрытая мобильная навигация имеет `inert` и `aria-hidden`, грейды получили
  отдельные доступные имена. Grid tracks и блок перед экзаменом исправлены
  после проверки реального горизонтального переполнения.
- Индикаторы подбора имеют размер 64×64; общий flex selector больше не
  растягивает их. Контекст потребности на мобильном располагается отдельной
  строкой. После отзыва доступа принятое приглашение явно показывает отзыв.
- Сохранённая подборка передаёт фактический статус текстовой модели, чтобы
  нейтральная константа отключённого компонента не выглядела результатом
  анализа текста. Регрессия проверена на создании и чтении подборки;
  повторные 21 domain test прошли после исправления.

## Измерения и границы

[Synthetic отчёт](../../evaluation/reports/latest.md): 2 400 форм, 28 800
заданий, все 166 families exercised, 0 oracle errors, P@5=0.9300,
nDCG@10 eligible=0.9627, end-to-end=0.7249, gate violations=0.
Алгоритмические задания проверялись независимыми reference solvers;
concept ответы имеют авторский ledger, независимые человеческие reviewers=0.
Эти результаты не являются оценкой реального найма или валидности грейдов.
Дополнительный TF-IDF компонент рассчитывается настоящей моделью, но отключён
по умолчанию: измеренный прирост недостаточен для основного алгоритма.

Датасеты и API ФСП организатором не предоставлены. Реестр и внешние достижения
в стенде демонстрационные и явно подписаны. Human pilot, IRT, эквивалентность
форм, реальные трудоустройства и промышленная нагрузка: `NOT_MEASURED`.

Произвольный Python/JavaScript код на этой Windows машине не запускается.
Предусмотрен отдельный Linux/gVisor judge с digest-pinned образами,
ограничением ресурсов, времени и вывода, без сети и host fallback. Его
адаптеры и границы протестированы, но настоящая Linux изоляция здесь не
проверялась. Кнопка отправки кода честно недоступна, SQL и задачи с данными
работают. [Инструкция judge](../isolated-judge.md).

Docker отсутствует. Compose профиль, Dockerfile и CI подготовлены;
registry manifests пяти официальных образов проверены и зафиксированы
по SHA256, но контейнерная сборка и удалённый GitHub CI не запускались.
Рабочий локальный запуск — нативный Windows путь, описанный в
[README](../../README.md).

Пароли окружения генерируются локально и не коммитятся. При аудите один
отладочный вывод теста раскрыл локальный административный пароль PostgreSQL;
он немедленно заменён, диагностический вывод ошибок подключения сокращён.
Наружу пароли и исходники не отправлялись.

## Браузерный аудит

[Машиночитаемый журнал](browser-smoke.json) фиксирует проверенные сценарии.
Это целевой ручной аудит через CUA, без заявления о полном покрытии всех страниц.

Проверены мобильный viewport 390×844 и настольный 1440×900. Перед экзаменом
и в активной попытке на мобильном `clientWidth=scrollWidth=375`: горизонтального
переполнения нет. Закрытое меню исключено из accessibility tree; четыре
кнопки грейда имеют отдельные имена и pressed state.

На вымышленном аккаунте аудита выполнены опрос, start, изменение тестового
ответа, autosave, reload и submit. Ответ восстановился, серверный deadline
не сбросился, результат получен; грейд не присвоен. Это проверка приложения,
не человеческий экзамен и не наблюдение для калибровки. В диалоге завершения
Tab/Shift+Tab остаются внутри и обходят действия по кругу.

Через интерфейс работодателя выполнены извлечение из текста с цитатами,
проверка и сохранение новой потребности с зарплатой, реальный подбор двух
допущенных кандидатов, сравнение, чтение evidence/вклада факторов и отправка
вымышленного приглашения без публикации вакансии. Кандидат открыл описание
компании и условия, отдельно подтвердил открытие контактов. Разрешение
появилось в приватности только у данной компании; отзыв выполнен через
отдельный диалог. Вымышленные профили помечены «Демоданные», профиль поясняет
загрузку категории из fixture. Отключённая текстовая модель обозначена явно.

Проверен настоящий browser login через Keycloak Authorization Code + PKCE
с возвратом в кабинет. Применяются локальные шрифты; интерфейс соблюдает
reduced motion. Скриншоты проверки — исторические локальные снимки, не включены в исходный архив сохранены отдельно.

INFO request logs реально поступают в Uvicorn и содержат UUID, method,
server-defined route template, status и duration. Query, body, headers и
значения динамических параметров маршрута не логируются. Целевой runtime
probe подтвердил исключение секретных маркеров из всех этих источников.
