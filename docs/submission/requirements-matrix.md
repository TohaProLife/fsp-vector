# ФСП Вектор: матрица требований и доказательств

Дата сверки: 11 октября 2026. Основание — все R01–R42 из карты требований и ответы экспертов. Текущая визуальная редакция — Contra Hire. Её frontend/API регрессии, recorded persisted readbacks, 29 chapter UI alignment checks MP4, source install и технический PDF имеют собственные датированные proof. Предыдущий локальный runtime-комплект прошёл CRC/hash verification. Презентация PPTX/PDF из 14 слайдов проверена отдельно. Публикационная редакция очищает исходники и обновляет сведения о составе решения; адреса материалов перечислены в README. Размещение файлов не отправляет конкурсную форму.

**Статусы:** `VERIFIED` — указанная реализация имеет содержательную проверку в описанном scope; `VERIFIED_HISTORICAL` — доказательство относится к прежней сборке; `PARTIAL_CURRENT` — текущая редакция наблюдалась только в перечисленной части сценария; `DEMO_ONLY` — явно демонстрационная интеграция; `STRUCTURAL_VERIFIED / HUMAN_NOT_MEASURED` — программный эксперимент без человеческой калибровки; `CONFIGURED_NOT_RUN` — конфигурация есть, запуск не проверен; `PENDING` — необходимый финальный файл, доступ или проверка не подтверждены. Презентация больше не исключена из scope. Ни один статус не является внешней сертификацией безопасности или качества найма.

Маршруты в таблице имеют prefix `/api/v1`, кроме явно указанного `/ready` и `/openapi.json`. `D` обозначает [test_domain_api.py](../../services/api/tests/test_domain_api.py), `B` — [test_backend_round2.py](../../services/api/tests/test_backend_round2.py), `P` — [test_postgres_concurrency.py](../../services/api/tests/test_postgres_concurrency.py), `O` — [test_contracts.py](../../services/api/tests/test_contracts.py), `Q` — [test_projection_performance.py](../../services/api/tests/test_projection_performance.py). Имена ниже — настоящие тестовые функции. Ссылки `P` относятся к историческим PostgreSQL checks с отдельной случайно именованной БД; основная БД не сбрасывалась. В последнем Contra-прогоне 268 tests +324 subtests PASS эти 14 opt-in checks заново не выполнялись. Старые browser-smoke/frontend/engine supporting audits читаются с их датой; новые визуальные факты определяет текущий Contra release.
