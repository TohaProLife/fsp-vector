## Что внутри

Презентация содержит 14 слайдов. Обязательные исходные слайды шаблона 7–11 сохранены на первых пяти позициях; шрифты встроены, в заметках есть сценарий выступления. PDF предназначен для просмотра без PowerPoint.

Видео показывает два кабинета, паспорт компетенций, сохранение профиля, переписку, объяснимый подбор, этап найма, отзыв доступа к контактам и доставку в локальную ATS. Все профили вымышлены. Показан сохранённый результат выполнения серверной рубрики синтетическим контрольным участником; новая регистрация и новая сдача экзамена в записи не повторяются.

Техническое руководство содержит 10 страниц. Для локального запуска, демонстрационных аккаунтов и проверок смотрите [корневой README](../../README.md). Дополнительно доступны [матрица требований](requirements-matrix.md), [OpenAPI](../api/openapi.json) и [заметки выступления](pitch-notes.md).

Контрольные суммы файлов находятся в `SHA256SUMS.txt` релиза. Исходники не содержат runtime, баз данных, сгенерированных секретов, материалов организаторов и сторонних репозиториев.

## Доступ и сдача

В поля формы вставляются внешние ссылки из таблицы. Локальный `localhost` не нужен: в поле «Прототип» используется полное видео. Работающее приложение запускается локально.

Загрузка материалов в GitHub не отправляет конкурсную форму. Команда отправляет её на платформе до **11 октября, 23:59 МСК** и сохраняет подтверждение.
