# ФСП Вектор

Паспорт подтверждённых компетенций и платформа найма ИТ-специалистов. Участник показывает навыки и достижения, а работодатель находит человека под конкретную задачу. Приглашения, переписка и этапы найма собраны в одном месте; доступ к контактам контролирует сам участник.

Проект команды **ИИ друны** для трека Федерации спортивного программирования на «Лидерах цифровой трансформации 2026».

## Что умеет платформа

- Специалист заполняет профиль, импортирует PDF-резюме, проходит опрос и экзамен. В паспорте видны источник, дата и результат каждого подтверждения.
- Экзамен поддерживает шесть специализаций и четыре грейда: формы, ответы, таймер и история сохраняются на сервере. Есть повторное тестирование и практика.
- Работодатель описывает потребность команды. Сервис помогает разобрать текст, подобрать и сравнить специалистов и объясняет, какие доказательства повлияли на результат.
- Приглашения содержат условия и зарплату. Встроены переписка, этапы найма, вакансии и отклики.
- Участник разрешает конкретной компании видеть контакты и может отозвать разрешение или заблокировать компанию.
- Есть PDF-паспорт, уведомления, почта и HTTP-интеграция с ATS.

Заявленные в резюме навыки, результаты экзамена, практика и демонстрационные записи ФСП отображаются отдельно. Выбор желаемого грейда не присваивает подтверждённую категорию.

## Запустить локально

Основной проверенный путь — **Windows, Python 3.14 и Node.js 24**, добавленные в PATH. Первичная установка требует интернета: скрипт скачает зависимости и локальные PostgreSQL, Keycloak, Java и Mailpit.

Скачайте [архив исходников](https://github.com/TohaProLife/fsp-vector/releases/download/v1.0.0-final/fsp-vector-source.zip) или клонируйте репозиторий. Откройте PowerShell в папке проекта:

```powershell
./scripts/setup.ps1
Push-Location apps/web
npm.cmd run build
Pop-Location
./scripts/start.ps1 -Production
```

Откройте **http://localhost:3000**. Терминал запуска остаётся открытым. Остановить стенд можно из другого терминала командой `./scripts/stop.ps1`.

| Роль | Почта | Пароль |
|---|---|---|
| Специалист | candidate@vector.local | VectorDemo2026! |
| Работодатель | employer@vector.local | VectorDemo2026! |
| Вторая компания | employer2@vector.local | VectorDemo2026! |

Это вымышленные демонстрационные аккаунты. Новый аккаунт создаётся через регистрацию; письмо подтверждения доступно в [локальном почтовом стенде](http://localhost:8025). Начальный профиль специалиста не получает подтверждённый грейд без экзамена.

API и интерактивная документация: http://localhost:8000/docs. Нужны свободные порты 3000, 8000, 55432, 8081, 8025, 1025 и 8090. Конфигурация и сгенерированные секреты хранятся в `.local`, данные и зависимости в Git не входят.

## Как устроен проект

Next.js / React отвечают за интерфейс, FastAPI — за предметные операции, PostgreSQL — за сохранение данных. Keycloak предоставляет OIDC, worker доставляет почту и события ATS через транзакционный outbox. Клиент не определяет оценки экзамена и права доступа к контактам.

| Каталог | Содержание |
|---|---|
| `apps/web` | Интерфейс и его проверки |
| `services/api` | API, экзамен, подбор, модели и миграции |
| `services/integrations`, `services/judge` | ATS и подключаемый изолированный исполнитель |
| `data`, `assessment-bank`, `evaluation` | Авторские задания, синтетические данные и воспроизводимая оценка |
| `scripts`, `deploy` | Локальный запуск, проверки и конфигурация развёртывания |
| `docs` | Руководство, OpenAPI и доказательства выполнения требований |

## Границы прототипа

ФСП-реестр демонстрационный: официальный API не предоставлен. ATS работает с локальным приёмником. Метрики получены на синтетических данных; человеческий пилот ещё не проводился. Произвольный код участника выполняется только через отдельный изолированный runner; без него функция недоступна. SQL и декларативные задания доступны на локальном стенде. Docker / Linux-профиль подготовлен, но на этой машине не запускался. Работающий сайт публично не развёрнут — прототипом для сдачи служит видео.
