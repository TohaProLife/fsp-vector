# Веб-интерфейс ФСП Вектор

Next.js и React: главная страница, регистрация и два рабочих кабинета — специалиста и работодателя. Запросы к `/api/v1` проходят через один origin к FastAPI; изменения сохраняются на сервере.

Полный локальный запуск описан в [корневом README](../../README.md). Для разработки уже настроенного проекта:

```powershell
npm.cmd ci
npm.cmd run dev
```

По умолчанию интерфейс доступен на `http://localhost:3000`, API — на `http://127.0.0.1:8000`. Адрес API задаётся через `API_ORIGIN`.

## Устройство

- `src/app` — маршруты и стили.
- `src/components` — оболочка кабинета, авторизация и общие элементы.
- `src/features` — профиль, экзамены, подбор, вакансии, найм и интеграции.
- `src/lib` — API-клиент, загрузка данных и правила отображения источников доказательств.
- `tests` — проверки обработчиков, сессии, сохранения и границ данных.

Авторизация использует cookie-сессию и CSRF-токен. Права, оценки экзамена и доступ к контактам определяет сервер. Неподтверждённые навыки, экзамен, практика и демонстрационный реестр ФСП отображаются отдельно.

Шрифты Prata, Golos Text и Inter, а также иллюстрация главной страницы хранятся в `public`. Интерфейс поддерживает клавиатурный фокус, адаптивные размеры и `prefers-reduced-motion`.

## Проверки

```powershell
npm.cmd run typecheck
npm.cmd run test:routes
npm.cmd run build
```

Проверки маршрутов требуют работающего API. Исполнитель произвольного кода подключается отдельно; без него соответствующая функция явно недоступна.
